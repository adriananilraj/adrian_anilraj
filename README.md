# Adrian Anilraj Portfolio — GSAP + Three.js Edition

A responsive, animated software engineering portfolio.

## Included

- `index.html`
- `styles.css`
- `script.js`

## Animation stack

- Three.js hero scene
- GSAP entrance choreography
- GSAP ScrollTrigger reveals and parallax
- Word-level hover sweeps
- Custom illuminated cursor trail

The libraries load through jsDelivr CDN, so an internet connection is needed for the enhanced animation. The content remains readable if a CDN is unavailable.
